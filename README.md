## 💭 프로젝트 소개
**지코바 치킨** 사이트를 리뉴얼한 웹 페이지로, 창업을 희망하는 고객을 타겟으로 사이트를 제작하였습니다.

<br>

## ✨ 주요 기능

### 1. 메인 페이지
- 메인 섹션 및 SNS : Swiper를 활용하여 슬라이드 효과 적용
- Fix 버튼
    - 탑 버튼 : 페이지의 가장 상위 섹션으로 이동

### 2. Header
- 로고 : 메인 페이지 상단으로 이동 가능
- 중앙 네비게이션 : 마우스 오버 시 서브 메뉴가 나타나고 글자 및 보더 효과가 보임
- 햄버거 버튼 : 전체 메뉴를 볼 수 있는 창이 나타나고, X 버튼으로 변경

### 3. 게시판 페이지
- 게시판 : 게시글 작성 및 리스트로 출력 가능
  (로컬 컴퓨터에서 MySQL로 데이터를 제작하여 사용해 해당 부분은 이미지로만 첨부)

## 🌱 개선 목표

- 디자인 : 좀 더 사용성이 높고 고객이 원하는 정보를 쉽게 찾을 수 있도록 개선
- 게시판 페이지 : 작성자 및 조회수 등 내용 추가
- 서브 페이지 : 사용자의 방문 목적을 파악하여 더 세부적인 내용으로 서브 페이지 제작
